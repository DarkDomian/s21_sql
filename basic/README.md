Hardly recomend to have docker & docker-compose for work.

Initialize containers with docker-compose:
```
docker-compose up -d
```

While containers is up, we can go to the [`localhost:80`](http://localhost:80).\
And enter using `trelawnm@student.21-school.ru` as login and `secretpassword` as password.

- host name: `postgres`
- port: `5432`
