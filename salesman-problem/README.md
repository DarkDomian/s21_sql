## SQL Algorithms - `salesman-problem`

<a href="ex00/team00_ex00.sql"><b>Exercise 00 — Classical TSP</b></a> — Implements the classic Traveling Salesman Problem to find the cheapest route visiting all cities and returning to the starting point. Uses recursive SQL queries to explore all possible paths and identify the minimum cost tour.

<a href="ex01/team00_ex01.sql"><b>Exercise 01 — Opposite TSP</b></a> — Extends the TSP solution to also identify the most expensive routes alongside the cheapest ones. Demonstrates how the same recursive approach can solve both optimization and worst-case scenario problems.
